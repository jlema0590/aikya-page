# Aikya ecosystem portal

Goal: present Harness, Forge and Mods as independent products using verified repository
content and the original Aikya navy/cyan/turquoise identity. Publish the portal to
this repository's GitHub Pages project URL.

Design: a spacious navy landing page, large geometric typography and a single
animated connection illustration explain the ecosystem. Product details, a factual
comparison and installation guidance provide the next steps. Controls remain
keyboard accessible; pause and reduced-motion modes keep the illustration readable.

Palette: navy #0b1f44, deep navy #07152f, panel #112139, cyan #0fb3f1,
turquoise #1fccba, text #edf4ff. Outfit is self-hosted under its OFL license;
terminal examples use the platform monospace stack.

Architecture: buildless browser HTML/CSS/JS, generated from small Node templates.
No framework or runtime dependencies, remote fonts, analytics or model requests.
Pages deployment uses the generated site/ folder and supports both main and manual
runs. Relative links work under /aikya-page/.
