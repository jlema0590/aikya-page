# Portal validation — 2026-11-23

## Verified implementation

The portal contains six generated static routes: landing page, Harness, Forge,
Mods, comparison and getting started. Content is English and is grounded in each
product's public main-branch README and stable-release endpoint checked on this date.
Harness and Forge remain independent products. Main features and published bundle
availability are distinguished; Forge has source guidance rather than an unavailable
public installer command.

The palette uses the original navy #0b1f44, cyan #0fb3f1 and turquoise #1fccba.
The connection illustration is code-native SVG, and the selected product panel
updates with native buttons and keyboard input. Ambient motion is pausable, follows
system reduced motion, and pauses while hidden/off-screen. The browser loads only
local static assets, including its licensed Outfit font; no model/account calls,
analytics, remote font provider or runtime dependencies are used.

## Observed local checks

- Node build and link/resource test passed: all six routes, local navigation,
  CSS imports and self-hosted font paths exist under the /aikya-page/ subpath.
- Nine Playwright browser tests passed in Chromium on macOS ARM64. These cover
  product selection with mouse and keyboard, pause/resume, reduced motion,
  navigation at 390/768/1440px, mobile button access, Forge availability guidance,
  and all six routes with JavaScript disabled.
- An extra 320px inspection found document width equal to viewport width.
- Desktop and mobile screenshots were visually reviewed. A first full-page capture
  taken after viewport changes tiled incorrectly; fresh browser contexts and reduced
  motion produced valid captures. DOM inspection confirmed one header and normal
  distinct sections. This was not treated as duplicated application content.
- actionlint 1.7.12 passed the Pages workflow. The deploy job requires the check job;
  only deployment receives Pages/OIDC write permissions.
- Browser navigation tests recorded no page errors. The final local test run passed
  without the redundant inherited colour-environment warning from earlier runs.
- Build/link and interactive controls were observed failing before implementation,
  then passing. A later CSS-asset check initially treated an SVG #fragment as a
  filename; the check now correctly distinguishes document-local references.

Screenshots are real browser output, not proposed AI mockups. See [desktop preview](hero.png).
Local evidence does not establish actual Safari, Firefox or physical-device testing.
