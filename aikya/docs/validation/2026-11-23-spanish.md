# Spanish portal validation — 2026-11-23

The six English routes now have Spanish equivalents under `/es/`. The EN/ES
selector retains the current page and works without JavaScript. Both languages
share product evidence, upstream links, local assets, pausable motion and the
original Aikya palette. Product names, commands and the six engineering phase
names remain unchanged. Public text, accessibility labels, metadata and dynamic
product/motion labels are translated. Engineering documentation remains English.

The build uses a reviewed translation catalog and rejects missing editorial
translations. It emits twelve HTML pages, canonical and alternate-language links,
and twelve sitemap entries. No translation API, automatic locale redirect, remote
font, tracking or account/model call is introduced.
