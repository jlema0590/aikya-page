# Aikya portal contributor instructions

- Harness, Forge and Mods are independent products. Do not describe Forge as a
  replacement for Harness or promise unsupported cross-product integrations.
- Keep public content and engineering documentation in English. Keep product
  claims grounded in the linked source repositories and their published releases.
- Never advertise an unavailable installer, invented usage values or unmeasured
  performance/token savings. Main-branch docs can be newer than stable releases.
- Runtime stays static, self-hosted and dependency-free. Do not add model calls,
  tracking, remote fonts or live account-usage polling to the portal.
- Plans and validation records belong under aikya/docs/plan and
  aikya/docs/validation. Keep motion pausable and respect reduced-motion settings.
- Run npm test before publishing. Review real desktop/mobile screenshots and
  preserve project-subpath navigation. Deployment uses site/ generated by the build.
